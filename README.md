# Live Code Clock

A minimalist real-time clock interface built with HTML, CSS, and JavaScript.

## Features

- Real-time date and time
- Analog clock
- Code-style time display
- Day progress percentage
- Dark mode
- Light mode
- Smooth clock-hand movement
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript

## Preview

![Live Code Clock](screenshot.png)

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. The clock will automatically display your current time.
